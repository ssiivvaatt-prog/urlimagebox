# プライバシーポリシー / Privacy Policy

このアプリ「URL Image Box」は、ユーザーが編集した画像の設定情報（フィルター、トリミング、回転など）を Google Drive にバックアップする機能を提供します。画像そのものは保存されません。

The app "URL Image Box" provides functionality to back up image editing metadata (such as filters, cropping, rotation) to Google Drive. The actual image files are not stored.

---

## 取得する情報 / Information Collected

- ユーザーが編集した画像の設定情報（メタデータ）
- Google アカウントの認証情報（OAuth による認可）

- Metadata of user-edited images (e.g., filter settings, crop dimensions)
- Google account authentication (via OAuth)

---

## 利用目的 / Purpose of Use

- 編集情報のバックアップ保存
- ユーザーが選択したファイルのみにアクセスし、他のファイルにはアクセスしません

- To back up editing metadata
- The app only accesses files explicitly selected by the user and does not access other files

---

## 第三者提供 / Third-Party Disclosure

- 取得した情報は第三者に提供しません
- 広告表示のために AdMob を使用しますが、個人情報は収集しません

- No collected data is shared with third parties
- AdMob is used for displaying ads, but no personal data is collected

---

## 保存方法 / Data Storage

- Google Drive に保存され、ユーザー自身が管理できます
- アプリはユーザーの明示的な操作によってのみ Drive にアクセスします

- Data is stored in the user's Google Drive and managed by the user
- The app accesses Drive only through explicit user actions

---

## データの削除 / Data Deletion

- ユーザーは Drive 上の保存データをいつでも削除できます
- アプリ側では自動削除や第三者削除は行いません

- Users can delete stored data from Drive at any time
- The app does not perform automatic or third-party deletion
